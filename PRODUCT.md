# Product

## Register

product

## Users

JNU students or technically curious users running a local-only elective helper before course selection opens. They are under time pressure, likely multitasking, and need clear status, low ambiguity, and fast recovery from login/session problems.

## Product Purpose

JNUAutoElective helps users capture a local login session, search candidate courses, build a precise pending list by teaching class ID, and repeatedly submit elective requests until a course is selected or the user stops the run.

## Brand Personality

Calm, precise, utilitarian.

## Anti-references

Avoid marketing-page styling, decorative dashboards, flashy gradients, oversized hero sections, and cute gamified controls. The interface should not look like a SaaS landing page or a generic AI-generated admin panel.

## Design Principles

- Make the next action obvious: search, add to pending list, start, stop.
- Separate discovery from commitment: query results are candidates; the pending list is the source of truth for抢课.
- Keep operational status visible without noise.
- Prefer familiar product UI controls over novelty.
- Treat sensitive credentials as local-only runtime state.

## Accessibility & Inclusion

Use readable contrast, standard form controls, visible focus states, responsive layouts, and reduced-motion-friendly interactions. Chinese UI copy is the primary language.
