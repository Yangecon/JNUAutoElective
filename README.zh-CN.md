# JNUAutoElective

[English](README.md) | 中文说明

JNUAutoElective 是一个面向暨南大学选课系统的本地自动化工具，提供网页监控台和命令行两种使用方式。它可以捕获本地登录会话、查询教学班、维护待抢列表，并按设定时间提交选课请求。

项目不会内置或提交任何用户凭据。登录信息只会保存在你自己的电脑上，默认文件名为 `credentials.json`，并已被 `.gitignore` 排除在版本控制之外。请不要把 `credentials.json` 发给他人，也不要上传到公开仓库、网盘或聊天群。

> 本工具仅供学习、交流与自动化研究。请遵守学校选课规定、系统规则和请求频率限制，并自行承担使用后果。

## 快速开始

运行前准备：

- Windows 电脑
- Python 3.9 或更高版本
- Chrome 或 Edge
- 可以正常访问暨南大学选课系统
- 有效的学校账号和当期选课资格

在项目根目录双击：

```text
start_web.bat
```

脚本会自动创建 `.venv`、安装依赖、启动本地服务，并通常打开：

```text
http://127.0.0.1:8765/
```

如果浏览器没有自动打开，请保持黑色命令窗口运行，手动访问以上地址。首次启动需要安装依赖，耗时会比后续启动更久。黑色命令窗口是本地服务进程，使用期间不要关闭。

## 推荐流程：网页控制台

### 1. 启动

双击 `start_web.bat`。启动页会显示北京时间，点击“开始”进入监控台。

### 2. 完成登录捕获

若页面显示“未登录”，程序会自动弹出 Chrome 或 Edge。

弹出的“获取 credentials”页面就是学校系统的正常登录页面，可以用二维码登录，也可以用账号密码登录。

登录成功后，程序会等待选课相关请求，随后在本地保存 `credentials.json`，关闭登录窗口，并把监控台状态更新为“已登录”。

注意：

- `credentials.json` 包含敏感本地会话信息。
- 不要把它发给他人。
- 不要上传到 GitHub、网盘、截图或聊天群。
- 会话失效、换批次或重新登录后，旧凭据可能无法继续使用，此时应点击“再次打开登录”或“重新登录”。
- 默认捕获等待时间为 120 秒。

### 3. 查询候选课程

在“课程查询”输入框中每行填写一个教学班号或课程名称，点击“查询课程”。

候选区会显示课程名称、教学班号、教师、开课单位、时间和地点等信息。

课程名可能对应多个教学班。请依据教师、校区、时间地点和教学班号核对，不要把课程号误当成教学班号。

### 4. 建立待抢列表

在候选区勾选目标教学班，点击“加入待抢”。再次检查左侧待抢列表，可逐项移除或清空。

只有待抢列表会被提交。候选课程只是发现和核对区域。

### 5. 设置时间与频率

| 设置项 | 含义 |
| --- | --- |
| 正式开抢时间 | 按北京时间（`Asia/Shanghai`）解释。请改成当次真实时间。 |
| 提前访问秒数 | 实际开始访问时间 = 正式时间减提前秒数。默认 60 秒。 |
| 提交间隔秒 | 相邻请求或轮次之间的等待；后端最低接受 0.02 秒。 |

如果按提前量计算出的时间已经过去，任务会立即开始。

频率越高并不等于成功率越高，也可能触发限流或违反系统规则；请使用审慎、合规的间隔。

### 6. 开始、观察与停止

点击“开始抢课”后：

1. 程序锁定当前待抢课程副本。
2. 等待至“正式时间减提前秒数”。
3. 按待抢列表顺序逐门提交。
4. 不断开始下一轮。
5. 若返回结果被尽力判断为成功，程序记录并自动停止。
6. 任何时候都可以手动点击“停止抢课”。

右侧“运行日志”是排查问题的首要依据。最终结果请同时在学校官方系统中核验，不要只依赖脚本文本判断。

## 课表页

点击右上角“课表”，可查看周一至周日、每天 1-13 节的网格。

课表数据来自当前页面已经查询到的课程，不等同于学校系统中的完整个人课表。只有教务返回字段能解析出星期和节次时，课程才会落入对应格子。点击左上角按钮可返回主页面。

## 命令行模式

命令行模式适合调试、试跑和可复现批量提交。

### 手动安装

```bash
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 捕获凭据

```bash
python -m jnu_auto_elective capture --out credentials.json
```

在浏览器中正常登录，支持二维码登录或账号密码登录。捕获成功后，程序会保存学号、选课批次、Cookie、Token 和 User-Agent 等字段。

### 准备 `classes.txt`

新建 `classes.txt`，每行一个教学班号；空行和以 `#` 开头的注释会被忽略。

```txt
# 每行一个教学班号
ABC123-01
DEF456-02
```

### 先查询，再提交

只查询不提交：

```bash
python -m jnu_auto_elective run --credentials credentials.json --classes classes.txt --dry-run
```

开始提交：

```bash
python -m jnu_auto_elective run --credentials credentials.json --classes classes.txt --rounds 3 --interval 1
```

参数：

- `--dry-run`：只查询不提交。
- `--rounds`：重复提交轮数，默认 `3`。
- `--interval`：请求间隔秒数，默认 `1.0`。

与网页模式不同，命令行 `run` 会按指定轮数结束，不提供页面中的定时等待和持续监控界面。

也可直接启动网页服务：

```bash
python -m jnu_auto_elective web
python -m jnu_auto_elective web --no-open
```

## 常见问题与排查

| 现象 | 处理方法 |
| --- | --- |
| 双击后提示找不到 Python | 安装 Python 3.9+，确认命令行可运行 `python --version`，再重新启动。 |
| 浏览器没有自动打开 | 保持黑色窗口运行，手动访问 `http://127.0.0.1:8765/`。 |
| Chrome/Edge 无法启动 | 确认至少安装一种受支持浏览器；查看日志中的驱动或启动错误。 |
| 一直显示未登录 | 在弹出窗口内完成正常登录并触发选课页面请求；超时后点击重新登录。 |
| 查询无结果 | 核对教学班号/课程名、当期批次、登录状态和网络；课程名搜索最多读取接口当前返回的候选。 |
| 开始按钮不可用 | 确认已登录、没有任务正在运行，且待抢列表非空。 |
| 任务立即开始 | “正式时间减提前秒数”已经过去；重新检查日期、时间和提前量。 |
| 显示成功但官方系统未确认 | 脚本是基于返回文本的尽力判断；以学校官方系统记录为准。 |
| 课表缺少课程 | 先在主页面查询课程；若时间字段不能解析，课程不会自动落格。 |

## 安全与合规清单

- 只在自己的电脑上运行，确认地址为本机 `127.0.0.1`。
- 不分享、不上传 `credentials.json`，不用真实凭据做截图或演示。
- 开始前逐项核对教学班号、教师、时间、地点和待抢列表。
- 使用学校允许的请求频率；遇到限流、异常或规则提示立即停止。
- 最终结果以学校官方系统为准，并在使用后关闭服务窗口。
